Command Pattern

Each button press is wrapped in a command object. The remote does not know how a light works; it only calls execute().

  • Command — interface with execute()
  • Concrete commands — TurnOnLightCommand, TurnOffLightCommand
  • Receiver — Light, does the real work
  • Invoker — RemoteControl, runs commands and keeps history
  • Factory — LightCommandFactory, injects services and builds commands
